## Présentation du projet

Ce portfolio a été développé dans le cadre de mes études afin d'exposer mes réalisations et mes compétences. L'application constitue une vitrine professionnelle performante, dotée d'une interface épurée.

## Stack technique

L'application repose techniquement sur le framework Next.js (basé sur React). L'interface utilisateur est construite à l'aide de Tailwind CSS, tandis que la bibliothèque Framer Motion est utilisée pour gérer les animations et les transitions de manière fluide.

## Fonctionnalités principales

Le site intègre un système de blog statique généré automatiquement à partir de fichiers Markdown (SSG). Il dispose également d'un composant modal sur mesure dédié à la consultation et au téléchargement de mon curriculum vitae, permettant aux visiteurs de consulter le document sans quitter le site.
